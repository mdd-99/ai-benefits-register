Settings

The tool starts with a recommended AI opportunity assessment framework, but you can tailor it to reflect your organisation's priorities. Changes apply consistently across all opportunities so scores remain comparable.

Opportunity Assessment Criteria and Weights

Rename, add or remove criteria and set the weighting for each. The total must equal 100% before a weighted recommendation can be calculated.

Total Weight: 100%
Assessment CriterionWeight %
Default framework: Business Value 20%, Customer Value 20%, Volume and Effort 15%, AI Suitability 15%, Data Readiness 10%, Risk and Oversight Readiness 10%, Measurability 10%.

Custom Category

Create an additional classification available on both the Opportunity Assessment and Benefits Register. For example, you might call this Department, Business Unit, Division, Strategic Priority, Program or Value Stream.

This classification is separate from Benefit Category. Benefit Category continues to describe the type of value delivered, while this field can describe where or how the organisation wants to group that value. It is set independently on each Opportunity and each Benefit, so linking an Opportunity to a Benefit does not automatically copy the value across.

How to Use

The tool is built around a simple lifecycle: configure how opportunities will be assessed, capture and prioritise opportunities, define and link benefits, then measure whether the expected value is actually realised.
1

Configure

Use Settings to tailor the assessment criteria and weights to your organisation. Recommended defaults are provided, but you can rename, add or remove criteria as long as the weights total 100%. You can also configure an additional Benefit classification, such as Department, Business Unit or Strategic Priority.

2

Assess

From the Opportunity Assessment register, select + Add Opportunity to open the entry screen. Capture the opportunity, business problem, customer experience opportunity and assessment scores. Use the ? icons for contextual guidance and complete every field marked with a red *.

3

Prioritise

Use the weighted score and recommendation as decision support. The Opportunity Assessment register provides the comparison view across all opportunities. Use View Fields to choose which columns are shown, and drag column headings — or items in the View Fields menu — to change their order.

4

Define Benefits

When an opportunity progresses, use Manage Benefits to create a new Benefit or link an existing one. A single Opportunity can link to multiple Benefits, and a single Benefit can be linked to multiple contributing Opportunities. In the Benefits Register, linked Opportunity IDs are clickable so you can open the relevant Opportunity directly.

5

Measure and Validate

Use the Add Benefit screen to record the baseline, target benefit, customer value, actual outcome and ongoing measure. The Benefits Register then provides the reporting view. Benefit Status stays locked to Not Started until Status reaches Implemented, since a benefit can only be tracked once the change is live in production, not while it is still an Idea, being Assessed or in Pilot. Keep reviewing Benefit Status and actual results to decide whether to scale, adjust or stop the initiative.

Using the Registers

Add and Edit: data is entered through the dedicated Add / Edit screens rather than directly in the register tables.

View Fields: choose which columns are shown in each register, and restore the default view at any time.

Reorder Fields: drag column headings directly in the register, or drag fields within the View Fields menu. Your chosen order is saved in the browser.

Action Icons: register rows use compact icons for actions such as Edit, Manage Benefits and Delete. Hover over an icon to see what it does.

Export: each register can be exported independently as a CSV file, an Excel workbook (.xlsx) or a full JSON backup, using the Export Data menu. The JSON backup covers both registers together and is the format expected by Import Data.

Dashboard

The Dashboard provides a portfolio view of opportunity prioritisation and benefits realisation.

All Dates: shows the full portfolio.

Custom Date Range: adds Start Date and End Date fields, filtering the Dashboard using Opportunity Review Date and Benefit Next Review Date.

Specific Benefit: focuses the Dashboard on one Benefit and its linked Opportunities. Date range controls are disabled while a specific Benefit is selected.

Custom Category: filters Benefits using the organisation-specific classification configured in Settings. The same classification is also available as an optional field on individual Opportunities, though the Dashboard filter itself only narrows the Benefits shown.

Clear Filters: restores the Dashboard to the default All Dates and All Benefits view.

Clickable Tiles: every KPI tile takes you to its underlying register. Where a tile represents a specific slice of the data — Benefits Realised, At Risk Benefits, Benefits In Progress, Actual Hours Released, Indicative Actual Capacity Value, Pipeline Hours and Indicative Pipeline Capacity Value — clicking it opens the Benefits Register filtered to just those matching records, with a banner showing the active filter and a Clear Filter button. Tiles based on the full portfolio (Opportunities Assessed, Initiatives Tracking Benefits, Target Hours Released, Indicative Target Capacity Value) open the register sorted to the most relevant column instead, since they are not tied to one status.

Benefits In Progress, At Risk Benefits, Pipeline Hours and Indicative Pipeline Capacity Value show the future potential still sitting in Benefits that are not yet Realised — useful for seeing what savings are still coming, separate from what has already been confirmed.

Actual Hours Released and Indicative Actual Capacity Value only include Benefits with a status of On Target or Realised. Measurements entered against Benefits still Tracking, At Risk or Not Started are excluded from these two totals until their status is confirmed, and any pending hours are noted beneath the tile. Target Hours Released and Indicative Target Capacity Value are not filtered this way, since they represent the plan rather than a confirmed result.

Scoring Guide

1 Very Low: little value, poor suitability or significant unresolved constraints.

2 Low: limited value or material issues need to be resolved.

3 Moderate: potential value exists, but further investigation is required.

4 High: strong value and good conditions for implementation.

5 Very High: compelling value, strong suitability and high confidence in delivery.

Assessment Framework

The default opportunity assessment framework is:

Business Value 20%  ·  Customer Value 20%  ·  Volume and Effort 15%  ·  AI Suitability 15%  ·  Data Readiness 10%  ·  Risk and Oversight Readiness 10%  ·  Measurability 10%

These values can be changed in Settings, but all Opportunities should use the same configured framework so their scores remain comparable. The configured weights must total 100% before the tool calculates a weighted recommendation.

Understanding Capacity Value

Capacity released is not automatically a financial saving. The tool calculates an indicative capacity value using time released and hourly cost. Treat it as a realised financial saving only where expenditure has genuinely been reduced or avoided.

On the Dashboard, the Actual figures are also filtered by Benefit Status: only Benefits marked On Target or Realised contribute to Actual Hours Released and Indicative Actual Capacity Value. This keeps the headline actual numbers to confirmed results rather than early or unconfirmed measurements. Each individual Benefit still shows its own actual calculation on the Add/Edit Benefit screen and in the Benefits Register regardless of status, so you can track progress before it is confirmed.
